# Mr. Gyros - электронное меню

Next.js 16 + React 19 + Tailwind 4. Меню для гостей (QR-код на столе), корзина с отправкой заказа в Telegram,
админка для персонала, PWA.

## Что где

| Путь | Назначение |
|---|---|
| `/` | меню для гостей, `/?table=5` запоминает номер стола (для QR-кодов на столах) |
| `/cart` | корзина, отправка заказа в Telegram |
| `/admin` | админка: цены, стоп-лист, «Выбор шефа», составы, фото, добавление/удаление позиций |
| `src/data/menu.ts` | стартовое меню и список категорий (категории правятся только здесь) |
| `src/lib/menuStorage.ts` | хранилище: Vercel Blob на проде, `.data/` локально |

Меню, сохранённое из админки, лежит в хранилище и имеет приоритет над `src/data/menu.ts`.
Пока админка ничего не сохраняла, показываются данные из кода.

## Локальный запуск

```bash
npm install
cp .env.example .env.local   # и заполнить ADMIN_PASSWORD (Telegram по желанию)
npm run dev
```

Без `BLOB_READ_WRITE_TOKEN` меню пишется в `.data/menu.json`, фото в `.data/uploads/` (папка в .gitignore).

## Переменные окружения

| Переменная | Обязательна | Что это |
|---|---|---|
| `ADMIN_PASSWORD` | да, для админки | пароль входа в `/admin`, минимум 6 символов |
| `BLOB_READ_WRITE_TOKEN` | да, на Vercel | выдаётся автоматически при подключении Vercel Blob к проекту |
| `TELEGRAM_BOT_TOKEN` | для заказов | токен бота от @BotFather |
| `TELEGRAM_CHAT_ID` | для заказов | id чата персонала (у групп начинается с `-100`) |
| `TELEGRAM_THREAD_ID` | нет | id темы, если в группе включены темы |
| `ORDER_TIMEZONE` | нет | часовой пояс времени в сообщении, по умолчанию `Europe/Moscow` |

Если Telegram не настроен, в корзине остаётся режим «покажите экран официанту».

## Деплой на Vercel

1. Import Git Repository -> выбрать этот репозиторий, настройки Next.js подхватятся сами.
2. Storage -> Create -> Blob -> Connect to project. Переменная `BLOB_READ_WRITE_TOKEN` добавится автоматически.
3. Settings -> Environment Variables: добавить `ADMIN_PASSWORD`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
4. Deployments -> Redeploy (переменные применяются только к новым деплоям).

Каждый `git push` в `main` автоматически выкатывает новую версию.

## Telegram-бот для заказов

1. В Telegram открыть @BotFather -> `/newbot` -> придумать имя и username. BotFather пришлёт токен вида `123456789:AAH...` - это `TELEGRAM_BOT_TOKEN`.
2. Создать группу для персонала (например «Mr. Gyros заказы»), добавить в неё бота и сделать его администратором.
3. Написать в группу любое сообщение, затем открыть в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найти `"chat":{"id":-100...}`. Это число со знаком минус - `TELEGRAM_CHAT_ID`.

## QR-коды на столах

Ссылка для стола N: `https://<домен>/?table=N`. Номер стола запоминается на телефоне гостя и подставляется в корзине.
